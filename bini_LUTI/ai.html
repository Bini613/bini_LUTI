Why no flowchart blocks

Your problem is a Land Use Transportation Interaction (LUTI) model: agents evaluate utilities over many alternatives, choose probabilistically, and relocate periodically. AnyLogic's Process Modeling, Pedestrian, Material Handling, Road, Rail and Fluid libraries all model flow of entities through a process (queues, servers, conveyors, tracks). None of them can express:

  • a multinomial logit choice over an arbitrary set of candidate grid cells,
  • a utility that sums weighted travel costs/times over all activity centres,
  • shortest-path travel time integrals over a link graph with congestion-dependent impedance,
  • endogenous rents driven by local population density,
  • a swappable road-investment algorithm.

Fitting that into a flowchart would obscure the logic and add nothing. An agent-based model with custom Java is the correct representation, so the model is set up as a clean agent-based workspace.
